# Contributing / 参与贡献

Please report OS/browser or Android/WebView versions, transfer mode, display/camera resolution, reproduction steps and a non-sensitive sample. Do not upload private files, keys or passwords. / 提交问题时请提供系统、浏览器或安卓 WebView 版本、传输模式、屏幕与摄像头分辨率、复现步骤及无敏感信息的样例，不要上传私密文件和签名密钥。

For codec changes, verify exact file bytes and Unicode text in both directions. For Android changes, distinguish mocked bridge tests from real-device camera and document-picker tests. Preserve third-party licenses. / 编解码修改应核验双向文件字节与 Unicode 文本；安卓修改请区分接口模拟测试与真机摄像头、文件选择测试，并保留第三方许可证。
