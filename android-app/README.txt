光邮离线 Android 2.0.0

安装与运行
安装 OpticalParcel-Android-2.0.0.apk，应用名称“光邮离线”。
Android 8.0（API 26）及以上；使用系统 Android WebView，建议保持该组件较新。
APK 为通用版本，不限定 ARM64，不需要谷歌服务、Node.js、Python 或互联网。
这是新的安卓原生宿主和手机界面，使用与网页端相同的离线编解码核心；
不是原来官方 CFC APK 的改名版本，也不是重新安装旧 APK。

四个入口
1. 收文件：Cimbar 摄像头接收。默认 Low 64×48；仍不稳可改 UltraLow 48×36。
   与电脑网页 1.3/1.4 的相同档位互通。两端模式必须相同。
2. 发文件：选择本机小文件或输入文本，生成 Cimbar 动态码图。
   文件上限仍为 1 MiB。准备完成后设置区折叠，可全屏展示。
3. 扫文本：摄像头扫描普通静态二维码，或从本地图片识别。
4. 制文本：UTF-8 + ECI 26 静态二维码，支持纠错、版本、掩膜、像素及留白设置。

使用要点
- 第一次打开摄像头时，允许安卓相机权限。
- 如要切换镜头，先停止，再选择镜头并重新打开；Cimbar 重开会清空接收进度。
- 摄像头预览位于主要操作区，更多参数默认折叠。
- 自动定位困难时展开预览下方“手动四角”，按左上/右上/右下/左下选择。
- 发码时建议全屏，普通屏幕空间较小时可将手机横放。
- 接收完成后点击保存，系统会让你选择文件名和位置。建议选本机目录。
- 普通二维码保存 PNG/SVG、识别文本保存 TXT 都使用相同的系统保存窗口。
- TXT 可带 UTF-8 BOM；二维码文本本身不自动添加 BOM。
- 复制文本调用安卓剪贴板。不会自动打开二维码里的网址。
- 应用前台保持屏幕常亮；切换到后台、关闭或重开接收会丢失未完成的进度。
  系统文件选择/保存窗口也会让应用离开前台，请在当前操作完成后再开始接收。
- “帮助”中可查看 Android/WebView 版本、最近错误、权限入口和开源许可。

离线与组件
所有网页脚本、二维码库和定制 WASM 核心都打包在 APK 内。
应用清单不申请 INTERNET、麦克风和广泛存储权限，只申请 CAMERA。
文件选择和保存使用安卓系统文件窗口，不需要全盘存储授权。
仍依赖系统 WebView 来执行网页核心；组件过旧/被禁用可能导致无法加载或使用相机。
这种情况可先查看帮助中的 WebView 版本，再在设备上启用/更新对应系统组件。

验证范围
已验证 Java 编译、DEX 生成、资源打包、签名和对齐；移动版界面和桥接流程
使用 Chromium 测试，模拟原生接口校验了 PNG、中文剪贴板和 UTF-8 TXT。
实体手机的摄像头、对焦、识别率与文件提供器行为仍需实际设备验证。
最终模拟器测试记录见 TEST-RESULTS.txt；不会把浏览器模拟测试称为实体机测试。

开发与许可
native src/ 与 web/ 为新增安卓代码；assets/optical/index.html 是生成的离线页面。
源码包包含对应网页/core 源码和许可。签名私钥单独备份，不在公共源码包内。
定制 Cimbar 核心仍为 MPL-2.0；Nayuki QR 生成器 MIT；jsQR Apache-2.0。
