Developer build notes (not required to install/run the APK)

Tested toolchain: Java 17.0.20, Android platform 35 r02,
Android SDK Build Tools 35.0.0 (D8 8.6.2), Python 3, Node.js for web source builds.
No Gradle dependency is required for the provided build pipeline.

Layout of source bundle:
  android-app/   native host, mobile adapter, assets, build scripts
  qr14/         corresponding web tool source, extended WASM core/source, licenses

1. Set ANDROID_SDK_ROOT to your installed Android SDK.
   Install platforms;android-35 and build-tools;35.0.0 with normal SDK tooling.
   If using a differently named tools directory, set ANDROID_BUILD_TOOLS to it.
2. Optional web rebuild: node qr14/source/build.cjs, then copy its output
   source/dist/Cimbar-Offline.html to qr14/Cimbar-Offline.html.
   The source bundle already contains the tested generated web page.
3. python android-app/prepare-assets.py
4. Point OPTICAL_KEYSTORE and OPTICAL_KEY_PASSWORD_FILE to your private PKCS12
   key (alias optical) and a UTF-8 file with its password. Keep them private.
   generate-signing-key.py can create a NEW signing identity; doing that does
   not allow updating an installed APK signed with an older key.
5. python android-app/build-apk.py

Output: android-app/OpticalParcel-Android-2.0.0.apk
The script runs AAPT2, javac, D8, ZIP alignment, APK signing, and verification.
Linux toolchain execution was tested. The script also resolves .exe SDK tools
on Windows and uses the platform-independent D8/apksigner JARs.

Tests:
tests/test-mobile.cjs uses Playwright and a mocked native bridge.
tests/emulator-smoke.py is a Linux-only Android 15 software-emulator test harness.
The emulator and adb must be launched within the same execution namespace.
