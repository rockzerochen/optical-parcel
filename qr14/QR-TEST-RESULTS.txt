Static text QR 1.4 validation — 2026-10-28
Environment: Linux, Chrome Headless Shell 145.0.7632.6, Node.js/Playwright.
No physical camera or Windows hardware recognition benchmark was performed.

PASS production HTML image recognition round trip:
Chinese punctuation, leading/trailing spaces, LF newlines, literal HTML tags,
emoji, a supplementary-plane CJK character, combining characters, ZWJ emoji.
Payload encoded as UTF-8 + ECI 26, with no inserted BOM.
Independent ZXing-C++ also decoded exact text and exact UTF-8 payload bytes.

PASS generation controls:
All four ECC levels and automatic/fixed masks 0–7; version 40 model;
browser checks for fixed version 8, ECC H, mask 3, scale 5, border 6,
giving an exact 305x305 PNG. Fixed versions reject overflow; oversized input
is rejected; stale generated images and downloads are disabled after edits.
No silent truncation or automatic ECC downgrade.

PASS character handling:
Unpaired UTF-16 surrogates rejected; intentionally supplied U+FEFF preserved;
UTF-8 sequences split over contiguous byte chunks recovered correctly;
explicit ECI takes precedence over manual fallback; invalid UTF-8 rejected.
External fixtures independently generated by Segno 1.6.6:
UTF-8 without ECI, GB2312 without ECI, GB18030 with ECI, Hanzi subset 1,
Kanji, default ISO-8859-1 (manual selection), numeric. Unsupported ECI
prevents text copying/saving rather than returning potentially garbled text.

PASS file outputs:
PNG download matches the generated canvas. SVG download succeeds.
TXT download matches exact UTF-8 content, both with and without optional BOM.

PASS camera simulation:
1280x720 canvas captureStream -> getUserMedia replacement -> actual video
capture -> bundled QR Worker -> exact Unicode text. Camera tracks stopped
after detection and after switching back to Cimbar. Capability/optics were
simulated; this does not measure real camera recognition rate.

PASS no page errors and no external HTTP requests during QR operations.
PASS existing Cimbar B/Bm/Micro/4C/Low/UltraLow small-file browser round trips
with exact SHA256, unchanged extended WASM bytes and configuration manifest.
Cimbar large-file validation from 1.3 remains documented in TEST-RESULTS.txt;
the core was unchanged for this release, so that test was not repeated.

UI layout inspected. Linux test host lacks Chinese fonts; Windows uses its
installed fonts. The runtime does not fetch fonts or libraries from the network.
